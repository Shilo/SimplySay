### Loading and competing instructions

The existing SessionStart script reads policy bytes, appends the execution/hash record, then writes the JSON `hookSpecificOutput.additionalContext`. A correct recorded hash therefore establishes execution of that script with those bytes. Because logging precedes stdout delivery, the record alone cannot prove that the host accepted the output or that the model applied it. Preserve exact package bytes, trust/readback, source/matcher, startup identity and supported hook completion/error evidence. A missing/failed completion is not an efficacy result. Do not add private wire interception, hidden-reasoning inspection or the previously blocked child-directive capture route.

The official [Hooks documentation](https://learn.chatgpt.com/docs/hooks) says SessionStart additional context enters developer context, non-managed hooks require trust, and oversized context can spill to a saved file with a preview. The previous compact policies are far below the documented approximate 2,500-token default spill threshold. That makes an ordinary size-limit explanation less likely; it does not prove actual acceptance, precedence or adherence in this binary. This paragraph summarizes the documented mechanism, not a new experimental loading pass.

Host-required opening and periodic updates remain binding. A policy cannot promise to suppress them. Its useful control is the information included and any discretionary extra messages. Accurate bookkeeping, job preparation and checklist recitation may still burden a reader; a real blocker, needed decision, material finding or expectation change can justify an update. A host-required message's existence and its reader value must be judged separately.

Long workflow context can accumulate task procedures and self-imposed reporting obligations. Keep source facts, required deliverables and actual constraints distinct from optional chat narration. The policy must not reduce work, verification, source coverage, files, code, structured/tool/memory traffic, copy-ready text or inter-agent detail. A policy instruction is still not technical isolation of those surfaces.
