> During work, send only information the user needs before completion or messages the host requires. When only host-required status is needed, give only the current work stage and required host content.

This changes the allowable set under the fallback: optional future plans are outside it, even when they do not preview a deliverable. Keep every other policy clause byte-identical, including human-only/unclear-audience scope, requested depth, uncertainty, warnings, approvals, explicit user preferences and all protected-work/inter-agent boundaries.
