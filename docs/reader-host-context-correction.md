## Exact adapter change

The optional manifest field is `assessor_host_facts`. Root can construct the only currently supported neutral facts with:

```javascript
manifest.assessor_host_facts = review.hostAssessmentFacts(['w1-study-evidence-audit']);
```

The object contains `case_ids`, `summary`, `source_role`, `source_sha256`, `provenance` and `limits`. Strict validation permits only the established canonical fact values and unique simple case IDs that occur in observed captured tasks. Unknown/unobserved cases, malformed IDs, private paths, altered summaries/sources/roles and extra instruction fields are refused. It is deliberately limited to this established host evidence, not a generic host-prompt configuration system. Root must select cases for which the pinned host and normal retained records support applicability; construction is not a new delivery/adherence test.

Only each listed observed task receives `host_communication_facts` in its assessor task data. All real arms using that task see the same context through their shared case ID, and both reversed reviewer packets receive identical facts. Controls retain their own original task facts; a control-task collision is rejected. Candidate messages, requests, files, packet instructions, response templates, comparison order, aliasing and controls are unchanged. The strict review schema is unchanged, and the facts cannot be quoted as if they were model-written chat.

The existing manifest path/hash already binds the selected data, mode and calibration source. The freeze additionally records `assessor_host_facts_sha256`; reporting verifies it against the hashed manifest and carries the facts into the new report only when supplied. Packet hashes bind the resulting task data. No file path is accepted in the optional data; provenance uses relative public project-document names only.

Without the optional field, packets/templates and report-data semantics stay unchanged. The default joint mode and the newly committed prospective independent mode retain their scoring code and thresholds. Historical source freezes still require their recorded Git revision; do not bypass a whole-source hash to replay an old cohort using this changed adapter. This implementation edits only prepare/report data flow, not diagnose/eligibility/validation choices.
