## Clear pass conditions, frozen before subject outputs

1. **Correctness/preservation:** every task-derived essential and requested depth remains present; actual generated files satisfy the frozen contract. Copy-ready material is complete standalone. Relevant uncertainty and honest check status survive. Existing actual child work retains its substantive calculations and caveats when saved/reused. Missing capture or unsupported checks are unverified, not passes. The entire native inter-agent boundary cannot pass while incoming instructions remain unreadable.
2. **Communication acceptability:** reviewers can locate the answer, important explanation/caveat and next action. They judge unnecessary explanation, unexplained jargon, redundant recaps and avoidable interruptions against the current user need. Accurate status can still be unhelpful if it adds no result, blocker, decision or necessary expectation. Necessary initial/long-task updates and requested technical detail are not automatically defects. No word-count target or fixed brevity template.
3. **Independent review validity:** reuse the four frozen omission/filler/depth/identity controls; each reviewer must satisfy all controls and evidence requirements before supporting a primary preference claim. Raw failed/unavailable reviews, ties and disagreements remain. Two opposite orientations expose sensitivity but cannot isolate order from reviewer variance.
4. **Design decision:** a policy cannot qualify by style if it fails preservation. No requirement to beat manually supplied instructions. If minimal meets the observed requirements as well as enabled, prefer the smaller text as the next design candidate, with installation/automatic application treated as legitimate convenience benefits requiring later packaged validation. If evidence reveals a material defect, name it; if missing evidence or contradictory judgments prevents a choice, declare inconclusive. No post-output threshold changes, another pilot round or criteria repair to obtain a win.

The independent case author may identify genuine missing prerequisites before freeze. Record any pretrial clarification here or in the frozen case manifest. No subject output may be used to revise the tasks or standards. Compatibility, disabling/removal and public release require a separately agreed test scope and budget; this round does not waive them.
