# Contact export contract

This is a local file exporter, with no live staff directory connection. Team JSON files contain {team, contacts}. Each contacts row has exactly contact_id, name, email, updated_at. contact_id is a nonempty stable string. updated_at is a valid ISO timestamp with an explicit timezone offset or Z.

The public API mergeContacts(teams) in src/merge.cjs accepts an array of team objects and returns contact rows. Traverse files in the supplied order, and rows in their array order. Merge only rows with the same contact_id. For that ID, choose the complete row with the newest actual timestamp instant; on an equal instant keep the first encountered row. An email address may be shared by distinct people and is never the identity key. Preserve the exact winning row values. Return one row per ID, ordered by when each ID was first encountered, even when its winning row appears later. Do not mutate input teams or contacts. Empty teams produce an empty row array.

loadTeams(paths) in src/load.cjs reads team JSON files in argument order. toCsv(rows) in src/csv.cjs returns the established CSV format: header contact_id,name,email,updated_at; these four fields in that order, comma separators, LF row endings, and a final LF including for a header-only export. Quote any field containing a comma, double quote, carriage return or newline, and double inner quotes. No other header or column changes. The CLI node bin/export.cjs FILE.json [FILE.json ...] prints only that CSV to stdout. It does not write to a directory service. Validation of malformed rows is outside this valid-input repair.
