# Experimental development evidence

The first screening batch contains all eight fixed subject conversations: D1 absent/A/B/manual and D2 absent/A/B/manual, 28 same-ID turns. There were no failed or replacement subjects. The [subject index](subject-index.json) binds 360 selected exported entries: 176 raw actual snapshot files and 184 public message/event/result/timing/metadata files. The existing exporter scrubber/visible-event whitelist and privacy scanner were reused. Raw artifacts keep their exact bytes; metadata paths and native IDs are pseudonymized. Profiles, sign-in caches, private reasoning and account inventories are excluded. All eight temporary sign-in copies were actually removed.

Native configuration, exact installed bytes, owned startup hash and continuation evidence passed in the observed arms. This establishes loading/isolation evidence for these runs, not model adherence, desktop compatibility or release readiness. The fixed supplied probes pass all eight cases. The independent actual-source audit additionally found a shared sub-millisecond timestamp limitation outside the frozen probes: identical D2 code collapses distinct instants under Date.parse. That literal-contract gap remains a failure and real-input precision is unknown; it is not automatically a policy-caused regression. No case, frozen probe or policy was edited to hide it.

The [source-screen projection](../screening-source-screen.json) retains actual file/native-record hashes and findings while pseudonymizing local paths with the existing scrubber. Its raw source hash is retained, and the original report stays outside Git. Independent verification inspected the full actual sources, tests, commands and usable standalone documents rather than relying on completion summaries. Test counts differ legitimately; counts alone are not effort or quality scores.

Review packets and judgments will be retained separately after the allocated blinded assessments. Raw CLI usage snapshots are recorded as reported and are not summed across resumed turns: their semantics may be cumulative. Account-wide quota is not an isolated cost measurement. These are automated development assessments, not measured human comprehension or a full inter-agent boundary pass. Original unreadable native helper instructions remain unverified.
