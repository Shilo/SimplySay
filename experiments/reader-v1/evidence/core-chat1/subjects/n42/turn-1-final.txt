The “300 dpi” label is output-size metadata—more precisely, **300 pixels per inch (ppi)** for an image. It tells software a default print size; it doesn’t measure sharpness. Changing that value with resampling disabled leaves the pixels unchanged.

The web copy has fewer pixels because it was downsampled. That reduces available detail and can explain softness at the same display size, even though both files say 300 dpi.

- **Website:** Use the **1000 × 750 web copy**. Its longest edge is within the 1200-pixel limit.
- **Community display:** Use the **4000 × 3000 original**. At 10 × 7.5 inches, it provides **400 ppi**, exceeding the 240 ppi requirement. The web copy would provide only **100 ppi**. The minimum dimensions for that print area are **2400 × 1800 pixels**.

Keep the original unchanged for future uses. These calculations establish which file meets the resolution requirement; without inspecting the image or a sample print, they don’t establish the finished print’s visual quality.
