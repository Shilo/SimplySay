# Shared files and recovery

The coordinator team uses a shared folder that synchronizes edits and deletions between its laptops. It is for day-to-day collaboration, not an independent retained copy.

A separate backup runs daily and retains earlier copies for 30 days. Its files are stored outside the shared folder. The job dashboard says recent jobs succeeded, but nobody has yet restored a file to check whether the retained copies can actually be used. The exact time of the last usable backup is not established.

The next coordinator needs access to the current shared files and a practical recovery route. This pack does not establish that a particular deleted file can be recovered. No live folder or backup service is accessible from this exercise.
